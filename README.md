# Python Electronic Store

A terminal-based electronic store management system developed in Python, simulating real-world retail operations for cameras, smartphones, and laptops. The project emphasizes **Object-Oriented Programming (OOP)**, data persistence, role-based access control, and automated reporting.

## Features

- **Object-Oriented Design:** Structured implementation using OOP principles.
- **Role-Based Access:** Separate roles and permissions for managers and employees.
- **Product Sales:** Manage product sales and process transactions.
- **JSON Data Storage:** Use JSON files as the system's primary data storage.
- **Data Backup:** Support backups in multiple formats, including TXT and CSV.
- **Seller Payments:** Handle payments to sellers based on sales.
- **Automated Reporting:** Generate reports identifying top-performing sellers and customers.

## Technologies

- Python
- Object-Oriented Programming (OOP)
- JSON
- CSV
- TXT File Handling

## Project Overview

This project demonstrates how Python can be used to build a structured, data-driven management system with multiple user roles, persistent data storage, sales workflows, backup mechanisms, and performance reporting — all through a command-line interface.
